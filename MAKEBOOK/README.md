# 主要解决的问题：
1. 生成大库，采用pt映射，这是唯一正确的原厂映射方法。修复了以前的pc映射不能命中的问题。
2. 适应pgns单一大pgn文件，批量生成开局库。
   
# 当前仍然存在的问题：
1. 开局库偏爱左手谱，即镜像着法权重相同，但左手谱排在前会优先命中。如炮八平五与炮二平五权重相同，但炮八平五命中。
2. 部分局面可以命中，但不能查询（另一个jni接口查不到）。如炮八平五，可以命中马2进3，可以查询有10个着法，可以命中，但是炮二平五可以命中马8进7，但是不能查询到任何着法。
